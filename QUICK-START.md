# Quick Start

Run ZORO directly in an **elevated** PowerShell window — no download step needed:

```powershell
irm https://raw.githubusercontent.com/zoronolonger/cwizxir/refs/heads/main/ZORO%20Tweaking%20Utility.ps1 | iex
```

If PowerShell isn't elevated, ZORO prints `[ERROR] Please run ZORO as Administrator!` and exits — reopen PowerShell **as Administrator** and run the command again.

For manual download, full requirements, and menu-by-menu usage, see [`INSTALL.md`](./INSTALL.md) and [`HOW-TO-USE.md`](./HOW-TO-USE.md).
